# Tool-Neutral Agent Skills

This directory is where portable, checklist-shaped skills live —
`create-adr`, `implement-issue`, `review-change`, `security-review`, or
any project-specific ones that follow the same shape (frontmatter +
short trigger description + a numbered or bulleted checklist, no heavy
narrative).

Organization-wide skills should be provided from a central location and
placed here at project setup, not authored fresh per project.
