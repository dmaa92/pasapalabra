# Security

- Do not commit secrets, credentials, tokens, or private keys. If one is
  committed by mistake, rotate it immediately — removing it from history
  is not sufficient on its own.
- Do not disclose vulnerability details in public Issues or PRs.

categories of risk this repository actually needs to defend against.
